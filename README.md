# SpriteX Lite

**Free Starve.io userscript**

[**Install SpriteX Lite**](https://raw.githubusercontent.com/applexdlol/spritex-lite/refs/heads/main/SpriteX.user.js)

## Installation

1. Install [Tampermonkey](https://www.tampermonkey.net/).
2. Click **Install SpriteX Lite** above.
3. Confirm the installation.
4. Open or reload [Starve.io](https://starve.io/).

Disable other Starve.io scripts before using SpriteX Lite.

**No key, payment or Discord login required.**

## Features

- Customizable interface and hotkeys
- FPS, ping and player information
- Health bars and healing timers
- Spectator and zoom controls
- Tracers and map overlays
- Targeting and combat controls
- Crafting and building automation
- Extractor, bread and furnace helpers
- Inventory tools

## Updates

Open the installation link again, confirm the update in Tampermonkey, then reload Starve.io.
