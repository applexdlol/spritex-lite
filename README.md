# SpriteX Lite

**Free Tampermonkey userscript · Version 1.3.9**

[**Install or update SpriteX Lite**](https://raw.githubusercontent.com/applexdlol/spritex-lite/refs/heads/main/SpriteX.user.js)

## Update required

Version 1.3.9 replaces the old public builds. The 1.3.4 and 1.3.5 build folders have been removed from the current repository. Open the install link and confirm the update in Tampermonkey, then reload Starve.io. Tampermonkey can also check this repository for updates automatically.

Deleting old files does not erase downloaded or cached copies, or historical Git commits. A public client-side script cannot remotely erase an installation.

## What changed

- Removed Simple Trees from Lite.
- Updated the menu to the current SpriteX layout, navigation and typography.
- Added a larger filled healing heart with a dark outline and bold white countdown on the player's left.
- Healing countdown: pink at 5 seconds or more, yellow below 5 seconds, green below 2 seconds; hidden at zero. The next healing tick is an estimate, not an attack cooldown.

## Installation

1. Install [Tampermonkey](https://www.tampermonkey.net/).
2. Open the install link and confirm.
3. Disable other SpriteX installations and conflicting game scripts. Run one SpriteX installation at a time.
4. Reload [Starve.io](https://starve.io/).

No SpriteX key, payment or Discord login is required.

## Included

- Performance readouts, detailed gauges, health bars, healing timers, information overlays and configurable tracers.
- Spectator camera and zoom controls.
- Basic automated targeting and combat controls, without Pro target lock-on.
- Automatic crafting, recycling, building and spike/wall/spiked-door controls.
- Extractor and bread helpers, furnace controls, planting and inventory layout options.
- Local interface preferences and configurable hotkeys.

**Simple Trees and Auto Emerald are not included.** Auto Farm, macro farming, pathfinding, Auto Treasure, base repairs, sandworm farming, replays, raid alerts, team inventory/position sharing, Pro workshop and Blueprint Studio are not included.

## Privacy and downloads

This free build does not bundle the Pro license/account client, player reporter, team relay, owner-announcement client or session-backup module. Preferences stay in your browser. The game and hosting providers operate their own services and may process requests under their own policies.

The installer downloads this repository's versioned Lite payload over HTTPS and checks its SHA-256 digest before evaluation. This repository contains generated, obfuscated distribution files, not private development source or the Pro payload. Obfuscation does not make public downloads secret.
