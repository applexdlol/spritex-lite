# SpriteX Lite

**Free Tampermonkey userscript · Version 1.3.5**

[**Install SpriteX Lite**](https://raw.githubusercontent.com/applexdlol/spritex-lite/refs/heads/main/SpriteX.user.js)

## Installation

1. Install [Tampermonkey](https://www.tampermonkey.net/) for your browser.
2. Open the install link above and confirm the installation in Tampermonkey.
3. Disable other SpriteX installations and conflicting game scripts. Run one SpriteX installation at a time.
4. Open or reload [Starve.io](https://starve.io/).

No SpriteX key, payment or Discord login is required for Lite. Tampermonkey checks this repository for installer updates. If startup reports an unsupported game client, check for updates; do not assume compatibility with future game changes.

## Included

- Performance readouts, detailed gauges, health bars, cooldowns, information overlays and configurable tracers.
- Spectator camera and zoom controls.
- Basic automated targeting and combat controls, without Pro target lock-on.
- Automatic crafting, recycling, building, spike/wall/spiked-door controls.
- Extractor and bread helpers, furnace controls, planting and inventory layout options.
- Local interface preferences, appearance options and configurable hotkeys.

**Auto Emerald is not included.** Auto Farm, macro farming, pathfinding, Auto Treasure, base repairs, sandworm farming, replays, raid alerts, team inventory/position sharing and Blueprint Studio are not included.

## Privacy and downloads

This free build does not bundle SpriteX Pro's license/account client, player reporter, team relay, owner-announcement client or session-backup module. Preferences are stored in your browser. The game and hosting providers operate their own services and may process requests under their own policies.

The installer downloads the versioned Lite payload from this repository over HTTPS and checks its SHA-256 digest before evaluation. This repository contains generated, obfuscated distribution files, not the private development source or Pro payload. Obfuscation does not make public downloads secret.
